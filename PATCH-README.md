# OTA Sports — New York market patch

This package is designed to be copied into the existing `otasports.info` GitHub repository without replacing the Philadelphia pages.

## Copy into the repo root

- `new-york/`
- `assets/styles.css` only if your repository does not already have the shared stylesheet or if you want this version.

## Add New York to the home page

A ready-to-paste market card is in `homepage-card.html`.

## Add New York URLs to sitemap.xml

Ready-to-paste `<url>` entries are in `sitemap-additions.xml.txt`.

## No JavaScript

All pages are static HTML + CSS.

## Important editorial rule

The Aug. 18 New York advance scan found no specific event that could yet be strongly verified on OTA. It DOES expose the sports-capable low-power services whose exact daily program schedules remain unavailable or uncertain. Do not convert those into specific listings until verified.
